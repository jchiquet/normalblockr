# normalblockr: implementation of the Normal-block model, Gaussian graphical model with latent clustering structure

The Normal-Block model (Tous, J., & Chiquet, J. (2025). An integrated
method for clustering and association network inference. arXiv preprint
arXiv:2503.22467.) can be used to analyse multivariate Gaussian data
with underlying latent structure. The model infers a structure of
statistical dependencies between the clusters identified (or given) in
the observations.
