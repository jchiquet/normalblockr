# Extracts fitted values from objects returned by \[NormalBlockBase()\] and its variants

Extract fitted values from an NormalBlockBase object.

## Usage

``` r
# S3 method for class 'NormalBlockBase'
fitted(object, ...)
```

## Arguments

- object:

  An object of class NormalBlockBase.

- ...:

  not used, only here for S3 compatibility

## Value

A matrix of fitted values extracted from the object.
