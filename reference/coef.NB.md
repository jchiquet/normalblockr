# Extracts model coefficients from objects returned by \[NB()\] and its variants

Extract coefficients from an NB object.

## Usage

``` r
# S3 method for class 'NB'
coef(object, ...)
```

## Arguments

- object:

  An object of class NB.

- ...:

  not use, only here for S3 compatibility

## Value

A matrix of coefficients extracted from the NB model.
