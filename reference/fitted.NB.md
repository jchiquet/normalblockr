# Extracts fitted values from objects returned by \[NB()\] and its variants

Extract fitted values from an NB object.

## Usage

``` r
# S3 method for class 'NB'
fitted(object, ...)
```

## Arguments

- object:

  An object of class NB.

- ...:

  not use, only here for S3 compatibility

## Value

A matrix of Fitted values extracted from the object object.
